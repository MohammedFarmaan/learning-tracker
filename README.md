# Learning Tracker

A personal software-engineering and UK job-search preparation tracker.

## What's inside
- Preparation roadmap and application plan.
- LeetCode question bank.
- System design topics.
- Amina project notes.
- UK company shortlist with sponsorship checks clearly marked for re-verification.
- Job application pipeline.
- Practical C# and engineering exercises.
- Deep Focus & Direct Relocation tab (anti-procrastination daily check-in, Pomodoro timer, Levels.fyi UK/NL/DE benchmarks, and deep engineering mastery gates).

## Progress and backups
Progress is stored in this browser using local storage. Use the export/import controls to back up progress and move it between devices. This static site does not automatically synchronise progress across browsers.

## Skilled Worker checks
A company having a sponsor licence does not mean every vacancy offers sponsorship. Verify the exact employing legal entity in the current [Home Office Register of Licensed Sponsors](https://www.gov.uk/government/publications/register-of-licensed-sponsors-workers) and confirm sponsorship with the employer for each vacancy. Check current [Skilled Worker visa requirements](https://www.gov.uk/skilled-worker-visa/your-job).
