🌐 Web-first vs iOS-native — the call

✅ Recommendation: Build Amina as a React PWA + .NET API first
Your stack is React + .NET. Learning Swift/SwiftUI to build native iOS on top of learning DSA + system design + UK move prep is too much at once. A React PWA gives you ~85% of the iOS feature set, ships faster, and is exactly what interviewers at Bumble, Trainline, and Deliveroo want to see in your portfolio.
⚠️ What you give up (and when to revisit)
Bluetooth mesh (Apple Multipeer Connectivity) is iOS-only — no web equivalent. Fake call with lock screen UI requires native. CallKit / IdentityLookup extension is native-only. These are v2 features — build the web version first, prove the core concept, then wrap it in React Native or Swift if you want the full PRD vision post-UK.

The real goal here is learning. Building Amina in React + .NET teaches you component architecture, real-time WebSocket comms, REST API design, auth, PostgreSQL, location APIs, and PWA service workers. That is system design through actual implementation — exactly what you said you want.

For React learning: Full Stack Open (fullstackopen.com) is the best free course on the planet for this stack — React + Node/Express + testing. Work through it while building Amina alongside.

📋 What Amina does (PRD v1.0)

A women's safety companion built on a local-first architecture — works across full network, degraded signal, and fully offline. Three connectivity tiers, crowdsourced safety map, real-time guardian view.

Journey Mode — woman sets destination + ETA; app tracks passively; auto-alerts guardians if she stops unexpectedly or goes silent for 60+ seconds
One-Tap SOS — hold 3s or shake phone 3× (discreet); sends SMS + push to all trusted contacts, triggers loud siren, broadcasts live location continuously
Crowdsourced Safety Map — anonymised heatmap of safe/suspicious zones built from all users' journey data; cached locally for offline use
Guardian View — up to 5 trusted contacts get a lightweight live map view; can send check-in pings; ranked by alert priority
Fake Call Escape — schedule or instantly trigger a realistic incoming call UI to safely exit uncomfortable situations
Safe Zones — mark home, masjid, work as safe; auto-reduce tracking frequency + auto-notify guardians on arrival
Bluetooth Mesh (iOS v2) — offline location relay through nearby Amina users; end-to-end encrypted; inspired by AirTag's offline finding network

🛠 Web version tech stack

This maps directly onto your existing React + .NET skills, extended with real-time and PWA concepts.

Frontend — React (TypeScript) + React Router + Zustand for state; Leaflet.js for maps; PWA service worker for offline caching
Backend — .NET 8 Web API (your stack!) + SignalR for real-time WebSocket; PostgreSQL + Entity Framework; Twilio for SMS fallback
Auth — ASP.NET Identity + JWT; OAuth (Google sign-in) — real auth you'd use in production
Hosting — Vercel (React) + Railway or Render (.NET API) + Supabase (PostgreSQL) — all free tiers available
Open source — public GitHub repo; MIT licence; contributes to your portfolio and OSS presence UK employers look for

🧠 System design concepts Amina teaches you

Building it answers real system design interview questions:

Real-time location at scale — WebSocket vs polling, GPS heartbeat batching, SignalR hubs — directly maps to "Design Uber"
Local-first architecture — IndexedDB offline queue, service worker sync, conflict resolution — maps to "Design Google Drive"
Fan-out notifications — SOS triggers multi-channel delivery (push + SMS + WebSocket) — maps to "Design a notification service"
Crowdsourced aggregation — anonymising + aggregating location data into heatmaps at scale — maps to "Design Twitter feed" / analytics
Auth + security — JWT, refresh tokens, end-to-end encryption for location packets — real production auth design
Anomaly detection — stateful journey monitoring, threshold logic, alerting pipeline — event-driven architecture in practice
